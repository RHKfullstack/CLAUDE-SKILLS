# Agent skills — CLAUDE.md adapter

> Generated by `scripts/build-adapters.mjs` from `skills/*/SKILL.md`. Do not edit by hand;
> edit the skill and re-run the script.

This adapter is an **index**. The instructions live in `skills/<name>/SKILL.md`. Pick the
smallest set that covers the task, open those files, and follow them.

Claude Code reads this file as project memory. Claude also discovers `skills/*/SKILL.md` natively when the directory is installed under `~/.claude/skills/` or `.claude/skills/`.

## Rules

1. **Load before acting.** Open the skill file and follow its procedure; never infer its contents from the name.
2. **A skill is a procedure, not prose.** Each phase ends in a named artifact (`EVIDENCE:` line). If you skip a phase, say which and why.
3. **Never mark a check `PASSED` that you did not run.** Use `PLANNED` or `UNAVAILABLE` with the command that would have run it.
4. **Stack bridge.** For a Laravel/PHP + MySQL/Redis or React/Vite target, also load `stack-php-mysql` — it supplies the executable command for each phase.
5. **Design tasks.** Web: `ui-design`. Any other medium (desktop, mobile, print, slides, social): `creative-designer`. Both, when the work spans web and print.
6. **One authority per subject.** `senior-data-migration-safety` owns migration measurement; `senior-release-gate` only summarizes it. `senior-test-adequacy` judges tests; `senior-work-audit` judges the change.

## Claude-specific

- Installing to `~/.claude/skills/<name>/SKILL.md` makes each skill available to every project; `.claude/skills/` scopes it to one repository.
- For Claude.ai or the desktop app, zip a single skill folder (the one containing `SKILL.md`) and upload it under Settings → Capabilities → Skills.
- The Agent SDK loads the same directory through its `skills` option.

| Host, container, secrets posture | `senior-system-hardening` |
